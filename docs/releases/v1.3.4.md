## KuroCat v1.3.4 — 美短白手臂与下巴遮挡修复

**美短伸向鼠标与键盘的两条手臂改为与静止前爪一致的纯白色。**

### 本次更新

- 美短伸出的手臂从肩根到爪尖统一为原有前爪暖白色，移除灰色上臂和灰白分界。
- 保留美短齐刘海和身体虎斑花纹，以及橘白白色手臂、闭眼修复、橙眼图标和更新提醒。
- 修复橘白转头时白色脸颊 / 下巴被身体斑块遮住的问题；头部范围内的脸部花纹保持前景，头部以外保留原身体花纹。
- 明确遮挡顺序：身体和脑袋图案在后，白色脸颊 / 下巴在前，胡须在最外层。
- macOS、Windows、Linux 同步修改，并更新美短与橘白六态预览。
- 已安装 v1.3.1 及以上版本的用户可从菜单选择「检查更新…」。

### 从原版或旧版升级

1. 先从菜单退出正在运行的旧版，避免同时运行两个版本。
2. macOS：解压，将新版 `KuroCat.app` 拖入「应用程序」并替换旧版；通常不需要删除设置。若 Finder 暂时仍显示绿色旧图标，可注销并重新登录后查看。
3. 如键鼠监听失效，在「系统设置 → 隐私与安全性 → 输入监控」重新授权 KuroCat，然后重启应用。原作者的版本不会自动更新为本 fork。
4. Windows：退出旧进程后替换 exe；Linux deb 使用 `sudo apt install ./对应文件.deb` 更新，tar 包解压后运行 `./kurocat`。

macOS 社区构建使用 ad-hoc 签名，未经过 Apple Developer ID 签名 / notarization；Windows 没有 Authenticode 发行者签名，首次打开可能出现系统提示。Linux 优先使用 X11；旧版 Ubuntu 20.04 / Debian 11 / UOS 不保证适用于预编译包，Wayland 的窗口及输入行为也有桌面环境限制。详见 [安装与排障](https://github.com/andyforfun168/KuroCatAndy/blob/v1.3.4/docs/DOWNLOADS.md)。
