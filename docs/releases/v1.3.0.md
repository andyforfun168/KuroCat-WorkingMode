## KuroCat v1.3.0 — 美短、橘白皮肤 · 淡金青绿瞳色

**macOS 用户下载 `KuroCat-macOS-universal.zip`，解压后替换旧版应用。此版包含闭眼 bug 修复和橙色眼睛应用图标。**

### 本次更新

- 皮肤菜单新增「美短（银虎斑加白）」与「橘白猫」，保留经典黑猫和暹罗猫，共四款。橘猫、三花本次未加入。
- 美短使用简化银灰虎斑、白胸和白手套；眼睛中间的白色平顶上移至额头斑纹下缘，保留确认后的齐刘海效果。
- 两款新皮肤的头部花纹跟随转头、抬头低头和歪头；身体色块随躯干动作，白手套随键鼠动作和第三只脚移动，尾巴条纹跟随摆动。
- 瞳色菜单新增「柔和琥珀」和「淡金青绿（参考图）」。后者按参考图取色：外圈淡金褐 `#B7A570`，靠近黑色瞳孔有少量灰青绿 `#8D9180`，随瞳孔移动和缩放。
- 在菜单中先选择皮肤，再选择喜欢的瞳色；选择会保存。切换到黑猫、暹罗猫时仍使用原有默认瞳色，新皮肤默认柔和琥珀。
- 保留 v1.2.1 的闭眼边缘修复及 macOS 橙眼图标；README 增加两款新皮肤的六态预览及选色说明。

### 从原版或旧版升级

1. 先从菜单退出正在运行的旧版，避免同时运行两个版本。
2. macOS：解压，将新版 `KuroCat.app` 拖入「应用程序」并替换旧版；通常不需要删除设置。若 Finder 暂时仍显示绿色旧图标，可注销并重新登录后查看。
3. 如键鼠监听失效，在「系统设置 → 隐私与安全性 → 输入监控」重新授权 KuroCat，然后重启应用。原作者的版本不会自动更新为本 fork。
4. Windows：退出旧进程后替换 exe；Linux deb 使用 `sudo apt install ./对应文件.deb` 更新，tar 包解压后运行 `./kurocat`。

macOS 社区构建使用 ad-hoc 签名，未经过 Apple Developer ID 签名 / notarization；Windows 没有 Authenticode 发行者签名，首次打开可能出现系统提示。Linux 优先使用 X11；旧版 Ubuntu 20.04 / Debian 11 / UOS 不保证适用于预编译包，Wayland 的窗口及输入行为也有桌面环境限制。详见 [安装与排障](https://github.com/andyforfun168/KuroCatAndy/blob/v1.3.0/docs/DOWNLOADS.md)。
