KuroCatAndy v1.4.3 — macOS 美术与互动更新

本次发布 macOS 11+ Universal（Apple Silicon / Intel）版，保留本 fork 橙眼图标及已有皮肤设置；未加入应用内更新器。

- 基础四款拎起时，背部抓取点跟随鼠标；背部轻微下垂，移除下巴灰线。
- 猫咪右手拿鼠标或数位板、左手拿倾斜键盘，外设跟随手部惯性。正常及拎起握笔均握住笔身，笔尾朝左上、笔尖接触数位板。
- 橘白拎起时采用暖橘背部和简化虎斑，斑块缩小并圆润收边，保留白色前爪；保留定稿美短、粉色鼻嘴和默认瞳色。
- 摸头、睡觉和半眯眼的闭眼线跟随当前瞳色。
- 拎起持续快速来回甩动，累计 1.2 秒有效甩动后出现转圈眼；仅改变表情，不晕倒。松手或重新拎起不清除恢复进度。
- 四款团睡统一采用原版黑猫主体轮廓；修复实际自动入睡额外歪头、低头及下沉造成的侧边尖角，保持呼吸与尾根衔接。

下载 KuroCat-macOS-universal.zip，先退出旧版再解压打开 KuroCat.app。使用相同设置存储位置，无需删除原设置。macOS 如全局监听失效，请重新授权输入监控并重启。本包为 ad-hoc 签名，未公证。

验证：Universal 双架构编译和签名检查；四款真实自动入睡流程、清醒/拎起渲染回归；30/60/120 FPS 下甩动触发和松手恢复检查。

本次新增效果以 macOS 为准。Windows / Linux 请使用此前的 v1.4.2 发布；本次不提供新平台包。给原作者的 PR 另行确认范围，尚未提交。
