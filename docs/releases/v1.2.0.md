## 🐱 KuroCat v1.2.0 — 本 fork 首次打包发布

适用于 macOS、Windows 和 Linux / 统信 UOS 的原生键盘鼠标桌宠。本仓库 fork 自 [chanke17/KuroCat](https://github.com/chanke17/KuroCat)，保留原作者署名和 MIT License；应用名称仍为 **KuroCat**。

**[主页功能与操作说明](https://github.com/andyforfun168/KuroCatAndy#readme)** · **[完整安装与排障](https://github.com/andyforfun168/KuroCatAndy/blob/v1.2.0/docs/DOWNLOADS.md)** · **[问题反馈](https://github.com/andyforfun168/KuroCatAndy/issues)**

### 下载哪个文件？

展开下方 **Assets**，按操作系统和 CPU 选择；文件名与主页 README 保持一致。

| 系统 | 文件 | 系统要求 |
| --- | --- | --- |
| 🍎 macOS，Apple Silicon + Intel 通用 | `KuroCat-macOS-universal.zip` | macOS 13+ |
| 🪟 Windows，Intel / AMD 64 位 | `KuroCat-Windows-x64.exe` | Windows 10 / 11 x64 |
| 🐧 Ubuntu / Debian / UOS，Intel / AMD 64 位 | `KuroCat-Linux-amd64.deb` | Ubuntu 22.04 构建基线；安装时检查依赖 |
| 🐧 Ubuntu / Debian / UOS，ARM64 | `KuroCat-Linux-arm64.deb` | 同上 |
| 🐧 其他 Linux，Intel / AMD 64 位 | `KuroCat-Linux-x86_64.tar.gz` | glibc 2.35+ 及兼容的 GTK3 等运行库 |
| 🐧 其他 Linux，ARM64 | `KuroCat-Linux-arm64.tar.gz` | 同上 |

`Source code (zip/tar.gz)` 是源码，不是可直接运行的安装包。`SHA256SUMS.txt` 是六个下载文件的校验清单，`LICENSE.txt` 是 MIT License。

### 首次运行

- **macOS：**解压后将 `KuroCat.app` 拖入「应用程序」并打开；前往「系统设置 → 隐私与安全性 → 输入监控」授权，再从菜单栏重启 KuroCat。此包为 ad-hoc 签名，未经过 Apple Developer ID 签名 / notarization，首次启动可能被系统拦截；请参照上方安装排障说明。
- **Windows：**直接运行 exe，通过小猫右键或托盘菜单调整。完全穿透可用 `Ctrl + Alt + Shift + P` 切换，或按住 Alt 后右键小猫。此包没有 Authenticode 发行者签名，可能出现未知发布者提示。
- **Linux：**优先用 `sudo apt install ./KuroCat-Linux-amd64.deb` 安装（ARM64 换对应文件），然后搜索 KuroCat 或运行 `kurocat`；tar 包解压后运行 `./kurocat`。优先使用 X11 会话。

**Linux 兼容性说明：**主页中列出的 Ubuntu 20.04、Debian 11 及旧版 UOS 不保证适用于本次预编译包。遇到 GLIBC / GLIBCXX 版本不满足，请按主页在目标机器源码编译。Wayland 的窗口行为与全局输入受桌面环境限制，尚未保证完整兼容；`input` 组仅影响原始输入设备读取权限。其他架构请源码编译。

### 校验与更新

macOS：`shasum -a 256 KuroCat-macOS-universal.zip`；Linux：`sha256sum KuroCat-Linux-amd64.deb`；Windows PowerShell：`Get-FileHash .\KuroCat-Windows-x64.exe -Algorithm SHA256`。将结果与 `SHA256SUMS.txt` 对应行比较。

更新前退出旧版，再替换应用 / exe 或安装新 deb。避免同时运行上游版和 fork 版。反馈请附版本、系统、CPU、具体文件名和复现步骤，不要附密码或私人输入内容。
