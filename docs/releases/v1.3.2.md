### 从原版或旧版升级

1. 先从菜单退出正在运行的旧版，避免同时运行两个版本。
2. macOS：解压，将新版 `KuroCat.app` 拖入「应用程序」并替换旧版；通常不需要删除设置。若 Finder 暂时仍显示绿色旧图标，可注销并重新登录后查看。
3. 如键鼠监听失效，在「系统设置 → 隐私与安全性 → 输入监控」重新授权 KuroCat，然后重启应用。原作者的版本不会自动更新为本 fork。
4. Windows：退出旧进程后替换 exe；Linux deb 使用 `sudo apt install ./对应文件.deb` 更新，tar 包解压后运行 `./kurocat`。

macOS 社区构建使用 ad-hoc 签名，未经过 Apple Developer ID 签名 / notarization；Windows 没有 Authenticode 发行者签名，首次打开可能出现系统提示。Linux 优先使用 X11；旧版 Ubuntu 20.04 / Debian 11 / UOS 不保证适用于预编译包，Wayland 的窗口及输入行为也有桌面环境限制。详见 [安装与排障](https://github.com/andyforfun168/KuroCatAndy/blob/v1.3.2/docs/DOWNLOADS.md)。
