## KuroCatAndy v1.4.1 — 新版功能与保留版白手臂

在本 fork v1.3.8 上合入原作者 v1.4.0（284f021）的功能与修复，保留本 fork 已确认的皮肤外观。

- 新增换装间，导入 / 导出 `.kurocat` 自定义皮肤及贴纸支持。
- 新增打哈欠、蜷缩睡姿、快速打字生气和甩鼠眩晕等表情动作。
- 新增数位板 / 触控笔模式、左右镜像、OBS 捕获设置、编辑模式、多语言和全屏自动隐藏等选项；同步平台输入与窗口修复。
- 美短、橘白伸出的两条手臂保持纯白，恢复本 fork 原来的肩部连接位置；保留已确认的脸颊、下巴、粉色鼻嘴和花纹，导出皮肤模板也保持一致。
- 默认瞳色仍为橘白→琥珀金瞳、美短→淡金青绿；保留橙眼 macOS 应用图标。
- 移除全部应用内更新检查、更新提醒、自动下载及替换；需要时从本仓库 Release 手动下载。

### 下载与升级

macOS 11+（Apple Silicon / Intel 通用）：**KuroCat-macOS-universal.zip**。Windows x64：**KuroCat-Windows-x64.exe**。Linux 按 CPU 选择 amd64 / arm64 deb 或 x86_64 / arm64 tar.gz。Source code 是源码，不是安装包。

先退出旧版再替换 App / exe。沿用原来的设置存储位置，升级无需删除设置；首次打开若系统要求，请重新授予输入监控权限。Linux tar 解压后运行 `bash install.sh`。macOS 为 ad-hoc 签名、未公证；Windows 未附发行者签名。六个安装包校验值见 **SHA256SUMS.txt**。
