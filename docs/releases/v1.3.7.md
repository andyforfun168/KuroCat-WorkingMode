## KuroCat v1.3.7 — 皮肤默认瞳色绑定

- 每次选择「橘白猫」，自动使用「琥珀金瞳」。
- 每次选择「美短（银虎斑加白）」，自动使用「淡金青绿」。
- 选好皮肤后仍可手动换瞳色；重新选择该皮肤会恢复对应默认值，选择会保存。
- 保留 v1.3.6 的粉色鼻子、2.5D 鼻嘴、白色手臂、圆润下巴及橘白右侧白缝修复。
- 保留橙眼应用图标和已同步的上游功能；没有应用内更新功能，手动从本仓库 Release 下载。

### 下载与升级

macOS 11+（Apple Silicon / Intel 通用）下载 **KuroCat-macOS-universal.zip**；Windows x64 下载 **KuroCat-Windows-x64.exe**；Linux 按 CPU 选择 amd64 / arm64 deb 或 x86_64 / arm64 tar.gz。Source code 是源码，不是安装包。

退出旧版后替换 App / exe；Linux tar 包可运行 `bash install.sh`。macOS 如监听失效，请在系统「输入监控」重新授权并重启。macOS 使用 ad-hoc 签名、未公证；Windows 未附发行者签名。六个安装包的校验值见 SHA256SUMS.txt。

### 验证

实际 macOS 菜单处理函数验证重复选择、手动覆盖、恢复默认及设置保存；原生皮肤 / 动作、闭眼回归；CI 编译四个目标。Windows / Linux 尚未完成桌面交互实机验证。
