## KuroCatAndy v1.4.2 — 新功能整合、睡眠尾根与眉毛修复

在 v1.3.8 基础上整合原作者 v1.4.1（412bc38）的功能，并保留本 fork 定稿的美短、橘白外观。

- 自定义 `.kurocat` 皮肤、换装间、皮肤文件夹与工坊入口；支持随头部/尾巴移动的贴纸。
- 数位板与压感笔模式；打哈欠、蜷缩睡姿、拎后颈、生气和眩晕互动。眩晕沿用上游原动作，不包含前扑实验动画。
- 全皮肤可开关白色贴纸描边、OBS 捕获模式、可视边框缩放、水平翻转、中英菜单、全屏自动隐藏及置顶和平台输入修复。
- 修复黑猫睡觉时尾根被白边隔开的现象：轮廓先画、填色后画，使尾巴自然连接身体。
- 修复橘白、美短生气时的异色/白色眉毛：裁切眼部开口形成皱眉，保留额头原有花纹。
- 保留橙眼应用图标、美短和橘白的纯白手臂及肩根衔接、圆润脸颊下巴和粉色鼻嘴；橘白默认琥珀金瞳，美短默认淡金青绿。
- 保留 v1.3.8 的跑马灯、三/四键彩蛋与尾巴互动。没有应用内检查更新、提醒、下载或自动安装功能。

- 同步 v1.4.1 的原生设置窗口、自定义 `.kurokb` 键盘、简化编辑框及旋转手柄、位置与朝向保存、小豆泥专属绘制及拖拽惯性/腹背朝向修复。
- 眉毛沿用上游新版在眼睛内部裁切的处理，避免重画额头色块；保持两款猫的原有花纹。

### 下载与升级

macOS 11+（Apple Silicon / Intel 通用）：**KuroCat-macOS-universal.zip**。Windows x64：**KuroCat-Windows-x64.exe**。Linux 按 CPU 选择 amd64 / arm64 deb 或 x86_64 / arm64 tar.gz。Source code 是源码，不是安装包。

先退出旧版再替换应用，沿用原设置存储位置，无需删除设置。macOS 如监听失效，请在输入监控重新授权并重启。macOS 为 ad-hoc 签名、未公证；Windows 未附发行者签名。安装包校验值见 **SHA256SUMS.txt**。

### 验证范围

macOS 原生皮肤、闭眼、输入与互动回归，以及 Universal 双架构编译和签名检查；Windows x64、Linux amd64 / arm64 由 CI 编译。Windows / Linux 桌面交互尚未实机验证。
