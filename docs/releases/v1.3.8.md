## KuroCat v1.3.8 — 键盘流光、尾巴互动与卡键修复

- 新增 RGB 键盘跑马灯，默认开启，可在菜单关闭；关闭后恢复原有键盘配色。
- 新增刚好同时按住四个物理键时「用尾巴按」彩蛋，默认开启，可独立关闭；保留三键用脚按。
- 鼠标靠近尾巴时会甩尾躲闪并自然回弹。
- macOS / Linux：改善漏收松键导致的卡键；macOS 增加休眠、屏幕休眠和会话切换时清理按键/鼠标状态，修复 Caps Lock 状态处理。
- Windows：Alt＋右键操作会等松开 Alt 再弹出菜单，避免菜单一闪就消失。
- 保留橙眼应用图标、粉色鼻嘴、白色手臂、皮肤遮挡修复及默认瞳色：橘白→琥珀金瞳，美短→淡金青绿。
- 没有应用内更新检查、下载或自动替换功能；以后从本仓库 Release 手动更新。

### 下载与升级

macOS 11+（Apple Silicon / Intel 通用）：**KuroCat-macOS-universal.zip**。Windows x64：**KuroCat-Windows-x64.exe**。Linux 按 CPU 选择 amd64 / arm64 deb 或 x86_64 / arm64 tar.gz。Source code 是源码，不是安装包。

先退出旧版再替换 App / exe；Linux tar 解压后可运行 `bash install.sh`。若 macOS 监听失效，请到系统「输入监控」重新授权并重启。macOS 为 ad-hoc 签名、未公证；Windows 未附发行者签名。六个安装包的校验值见 **SHA256SUMS.txt**。
